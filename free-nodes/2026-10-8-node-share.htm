第三章：安装实操 —— 三大平台一次说透

下载完成后，安装环节因系统而异。这里我分享一些我踩过坑后的经验。

Windows 用户：如同安装普通软件，但注意“绿色版”

你下载的可能是一个 .exe 安装程序，也可能是一个 .zip 压缩包。 - 如果是安装包： 双击运行，一路点击“Next”。在安装路径选择时，建议不要安装在 C 盘系统盘（除非你的 C 盘空间极大），避免因权限问题导致配置写入失败。接受许可协议后，等待安装完成。 - 如果是压缩包（绿色版）： 这是更推荐的方式。解压到你想要的目录（例如 D:\DarceClash），找到 Darce.exe 或 clash.exe 主程序，右键发送快捷方式到桌面即可。运行后，它会在任务栏托盘区生成一个小图标，所有操作都通过右键菜单或双击图标完成。

特别注意： Windows 防火墙可能会弹出拦截提示。请务必勾选“专用网络”和“公用网络”的允许访问，否则代理无法正常工作。

macOS 用户：拖动安装与“已损坏”的破解

macOS 的安装非常优雅。 1. 打开下载的 .dmg 镜像文件。 2. 将左侧的 Darce Clash.app 图标拖入右侧的“应用程序”文件夹。 3. 打开“启动台”，找到并点击运行。

常见坑： 由于签名问题，第一次打开可能会提示“无法验证开发者”。此时，请前往“系统偏好设置” -> “安全性与隐私”，点击“仍要打开”。如果提示“已损坏”，请在终端中执行 sudo xattr -d com.apple.quarantine /Applications/DarceClash.app，这能解决绝大多数“损坏”假象。

Linux 用户：终端下的从容

Linux 安装最灵活，但需要一点命令行基础。 - 如果你下载的是 .deb 包（适用于 Debian/Ubuntu），在终端中切换到下载目录，执行： bash sudo dpkg -i DarceClash_linux_amd64.deb 如果报依赖错误，执行 sudo apt-get install -f 修复。 - 如果你下载的是 .rpm 包（适用于 Fedora/openSUSE），执行： bash sudo rpm -ivh DarceClash_linux_amd64.rpm - 如果你下载的是 .tar.gz 压缩包，解压后直接运行其中的二进制文件即可。

安装完成后，通常可以在应用菜单的“网络工具”或“互联网”分类下找到它。

第四章：核心配置 —— 从“能跑”到“跑得漂亮”

安装只是热身，配置才是灵魂。很多人以为导入订阅就万事大吉，其实不然。

4.1 配置文件：从“天书”到“白话”

Darce Clash 的核心是一个 YAML 格式的配置文件。如果你不想手动编辑，可以在图形界面中操作。但理解基础结构，有助于你排查问题。

一个最基础的配置片段如下：

```yaml proxies: - name: "香港节点01" type: ss server: hk01.example.com port: 8388 cipher: aes-256-gcm password: "你的密码"

proxy-groups: - name: "自动选择" type: url-test proxies: - "香港节点01" - "日本节点02" url: "http://www.gstatic.com/generate_204" interval: 300 ```

解读： - proxies：定义了具体的代理服务器信息。 - proxy-groups：定义了策略组。url-test 表示自动测速，选择最快的节点。这是实现“自动加速”的关键。 - rules：定义分流规则。例如，访问 Google 走代理，访问国内网站直连。

图形化操作建议： 在“设置” -> “配置”中，你可以直接粘贴订阅链接，Darce Clash 会自动拉取并解析。对于新手，强烈建议使用订阅链接，而不是手动逐条添加节点，这样更新维护都方便。

4.2 连接与测速：验证是否“起飞”

配置好节点后，在“代理”页面选择你刚才配置的“自动选择”策略组，点击“连接”按钮。

这时，Darce Clash 会启动本地的一个混合代理端口（默认通常为 7890），你需要将系统代理设置为该端口。软件通常会自动开启“系统代理”开关。

如何测试速度？ 不要只看 YouTube 视频。建议访问 speedtest.net 选择代理所在地区的服务器进行测速。更专业的方法是，在终端中 curl -x http://127.0.0.1:7890 -o /dev/null -s -w '%{time_total}\n' https://www.google.com，观察返回的时间。

4.3 进阶技巧：规则分流与局域网共享

  • 规则分流： 在“设置” -> “规则”中，你可以自定义哪些域名走代理，哪些直连。例如，添加 DOMAIN-SUFFIX,baidu.com,DIRECT，让百度访问直连，不占用代理带宽。
  • 局域网共享： 如果你想让手机或平板也用上这台电脑的代理，开启“允许局域网连接”选项。然后手机连接同一 WiFi，将手机代理设置为 电脑IP:7890。这对于没有代理客户端的设备（如游戏主机）非常有用。

第五章：常见问题“急诊室”—— 别慌，问题不大

即使再熟练的用户，也会遇到问题。这里我整理了几个高频故障的解法。

Q1: 连接失败，日志一直报错？ - 检查订阅是否过期： 大多数机场订阅有有效期，过期后节点信息会失效。 - 检查系统时间： 证书校验依赖时间，如果系统时间不准，会导致 TLS 握手失败。 - 更换端口： 如果 7890 端口被占用，在设置中改为 7891 或随机端口。

Q2: 速度很慢，即便选择了最快的节点？ - 尝试“负载均衡”策略组： 将 url-test 改为 load-balance，它会将请求分散到多个节点，有时能突破单节点速度瓶颈。 - 关闭其他占用网速的程序： 比如云盘同步、在线备份。

Q3: 更新软件后配置丢失？ - 这是常见问题。更新前，请备份 config.yaml 文件。在 Windows 上它位于配置目录下，macOS 在 ~/.config/darce/。

Q4: 如何彻底卸载？ - Windows 使用控制面板卸载，macOS 将 App 拖入废纸篓，并删除 ~/Library/Application Support/DarceClash 下的残留文件。

AEAD 加密防止数据篡改、重放攻击和流量特征泄露。在高封锁环境下使用，可保证节点长期可用，提升数据安全和连接稳定性，同时降低被检测风险。

Trojan 协议是如何伪装流量的？
Trojan 利用 HTTPS 协议进行传输伪装，通过 TLS 加密实现高度隐蔽性。它让代理流量看起来与普通网站访问完全相同，从而难以被防火墙检测，是目前安全性较高的代理方案之一。
如何优化 Clash DNS 解析速度？
可在配置文件中启用 fake-ip 模式或使用高质量的 DoH 服务（如 Cloudflare、AliDNS）。同时将 `fallback-filter.geoip` 设置为 true，避免国内域名被错误解析到境外，提高解析效率。
Surfboard 的规则文件如何支持广告屏蔽？
规则文件可添加广告域名或 URL 列表，将请求重定向或阻断。结合策略组和自动更新，Surfboard 可实现全局广告屏蔽，提高浏览体验并节省带宽。
V2Ray QUIC 模式适合哪些网络环境？
QUIC 基于 UDP 协议，支持多路复用和零握手，适合高丢包和不稳定网络环境。可提升视频、游戏和即时通讯流量的稳定性和访问速度，提高网络体验。
Nekoray 支持节点批量更新吗？
支持。Nekoray 可通过订阅 URL 批量下载最新节点并替换旧节点。结合定时更新功能，可保持节点列表最新，减少手动维护和配置工作。
